# Copy Gmail Address Extension

A lightweight Chrome extension that adds a convenient copy button next to Google account email addresses across Google products.

The extension works wherever Google displays account information, making it easy to copy your email address with a single click.

## Features

✅ Copy active Google account email address with one click

✅ Works across Google services including:
- Gmail
- Google Search
- Google Maps
- Google Drive
- Google Docs
- Google Sheets
- Google Calendar
- Google Photos
- Other Google products

✅ Copy all email addresses detected on the current page

✅ Display total number of detected email addresses

✅ Lightweight and fast

✅ No tracking

✅ No analytics

✅ No data collection

## Installation

### From Source

1. Clone this repository

```bash
git clone https://github.com/YOUR_USERNAME/copy-gmail-address-extension.git
```

2. Open Chrome and navigate to:

```
chrome://extensions
```

3. Enable **Developer Mode**

4. Click **Load unpacked**

5. Select the extension folder

6. The extension is now installed

## How It Works

1. Open any Google product.
2. Click your Google profile avatar.
3. A copy button appears next to your email address.
4. Click the button to instantly copy the email address.

### Copy All Emails

The extension popup also includes a feature to:

- Scan the current page
- Detect email addresses
- Show the total count
- Copy all detected emails

## Permissions

The extension only requests the permissions necessary to function.

- activeTab
- scripting
- storage

## Privacy

This extension:

- Does not collect personal information
- Does not transmit data to any server
- Does not use analytics
- Does not track users
- Does not store copied email addresses

All processing occurs locally within your browser.
